# Security Policy

## Supported Versions

Only the latest tagged minor version receives security fixes.

## Reporting a Vulnerability
Do **not** open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository: open the repository's **Security** tab and choose **Report a vulnerability**. If private reporting is unavailable, contact a maintainer privately through GitHub without posting sensitive details publicly.

Include reproduction steps, impact, affected versions, and suggested mitigations if known. Avoid sharing credentials, personal data, or unrelated third-party information.

## Disclosure
- We aim for a fix or mitigation within 14 days for high severity issues.
- Public disclosure occurs after a patch is available or by mutual agreement.
